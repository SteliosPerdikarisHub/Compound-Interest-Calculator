# Compound-Interest-Calculator
A simple Python program that calculates the future value of an investment using compound interest.


## Features

- Calculates the future value
- Calculates total profit
- Calculates total percentage return
- Validates user input

## Formula

FV = PV × (1 + r)^n

## Example

Input:

Initial investment: $1000
Annual interest rate: 8%
Years: 5

Output:

Future value: $1469.33
Profit: $469.33
Total return: 46.93%

## Limitations

- The calculator assumes a constant annual interest rate.
- It does not account for taxes or fees.
- Interest is compounded once per year.
